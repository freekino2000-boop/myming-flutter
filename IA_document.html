04  AppState 메서드 · 상태 흐름

전역 상태 AppState의 공개 메서드 목록 및 호출 화면

메서드 시그니처 동작 호출 화면 영속화
earn() void earn(String icon, String name, int amount) walletAmount += amount, ledger 추가, notifyListeners H-03, N-01, N-02, G-02~G-05, F-01, OW-01 saveToPrefs()
spend() void spend(int amount) walletAmount -= amount (잔액 부족 시 무시), ledger 추가 SP-01, B-01 saveToPrefs()
addLedger() void addLedger(icon, name, amount, type) LedgerEntry 생성 후 ledger.insert(0, …) earn() / spend() 내부 호출 간접 (earn/spend 통해)
readCNArticle() void readCNArticle() cnReadCount++, 3회 시 cnMissionDone=true, earn +30 N-02 saveToPrefs()
doAttendance() void doAttendance() lastAttendanceDate=오늘, earn +10 H-03 saveToPrefs()
canAttendToday bool get canAttendToday lastAttendanceDate != today H-03 —
addSteps() void addSteps(int count) steps += count, rate = hasManhwaBoost ? 0.015 : 0.01
walletAmount += count × rate, ledger 추가		 H-01 (pedometer 스트림) saveToPrefs()
buyBooster() void buyBooster(String effect, String name, int price) walletAmount -= price, effect 에 따라 부스터 플래그 true SP-01 (부스터 탭) saveToPrefs()
startSession() void startSession() 최초 호출 시 firstAccessDate 저장, _sessionStart 기록.
앱 포그라운드 진입마다 호출 (이미 세션 중이면 무시 ??=).
⚠ totalSecondsInApp은 저장하지 않음 → 앱 종료 시 초기화		 main.dart (initState + AppLifecycleState.resumed) firstAccessDate만 저장
pauseSession() void pauseSession() _sessionStart 기준 경과 초를 totalSecondsInApp에 누적 후 _sessionStart = null.
백그라운드 전환 시 호출 (AppLifecycleState.paused).
앱 완전 종료(kill) 후 재시작 → totalSecondsInApp = 0으로 초기화		 main.dart (AppLifecycleState.paused / dispose) 저장 안 함 (세션 한정)
currentSessionSeconds int get currentSessionSeconds DateTime.now().difference(_sessionStart).inSeconds.
_sessionStart == null 이면 0		 SP-01 _DwellTimeCard —
totalSecondsWithCurrent int get totalSecondsWithCurrent totalSecondsInApp + currentSessionSeconds.
앱 재시작 후엔 totalSecondsInApp = 0 이므로 = currentSessionSeconds		 SP-01 _DwellTimeCard —
loadFromPrefs() Future<void> loadFromPrefs() shared_preferences에서 초기 로드.
totalSecondsInApp은 로드하지 않음 (앱 시작마다 0으로 초기화)		 main.dart (앱 시작) 읽기 전용
saveToPrefs() void saveToPrefs() walletAmount, steps, 미션 상태, firstAccessDate 저장.
totalSecondsInApp은 저장하지 않음		 earn/spend/buyBooster/addSteps/startSession 후 자동 호출 쓰기
